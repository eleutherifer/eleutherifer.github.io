# Разное

* [generation-warp](https://generation-warp.github.io/)  
Форк генератора конфигов для WARP VPN. Об отличии форка от оригинала читайте там в [README](https://github.com/generation-warp/generation-warp.github.io/blob/main/README.md).  
* [generation-proton](https://generation-proton.github.io/)  
Форк генератора конфигов для Proton VPN. Об отличии форка от оригинала читайте там в [README](https://github.com/generation-proton/generation-proton.github.io/blob/main/README.md).  
* [proton-convertion](https://proton-convertion.github.io/)  
Форк конвертера конфигов для Proton VPN. Об отличии форка от оригинала читайте там в [README](https://github.com/proton-convertion/proton-convertion.github.io/blob/main/README.md).  
* [Форк usque-app](https://github.com/eleutherifer/usque-app/releases)  
Android-приложение Usque позволяет подключиться к WARP VPN по VPN-протоколу MASQUE.  
В форке заменена используемая для регистрации ссылка на API на незабаненную ссылку на API для Zero Trust, что позволяет зарегистрироваться в Cloudflare без включения VPN.  
* [Форк warpscout](https://github.com/eleutherifer/warpscout/releases)  
warpscout показывает в том числе к каким серверам (colo) происходит подключение при использовании различных эндпоинтов WARP VPN.  
В форке заменена используемая для регистрации ссылка на API на незабаненную ссылку на API для Zero Trust, что позволяет зарегистрироваться в Cloudflare без включения VPN.  
* [Белый список SNI для QUIC (HTTP/3) для сетей Proton VPN](https://raw.githubusercontent.com/eleutherifer/eleutherifer.github.io/refs/heads/main/whitelist_for_quic.txt)  
267 SNI, из них три нероссийских: `pypi.org`, `deepseek.com`, `joomag.com`,  
и есть 2 SNI из сети Cloudflare: `360tv.ru`, `nplus1.ru`.
